# La Pizarra · Arma tu once

Pizarra táctica de fútbol hecha con HTML, CSS y JavaScript puro (sin dependencias ni paso de compilación).
Es una PWA: se puede instalar y funciona sin conexión.

- Esquemas: 4-3-3, 4-4-2, 3-5-2 y 4-2-3-1
- Arrastra jugadores (o usa las flechas del teclado) y ponles nombre
- La alineación se guarda en el dispositivo (localStorage)
- Desplegada en Vercel (PaaS)

## Ejecutar en local
    python3 -m http.server 8000   # luego abre http://localhost:8000

## Desplegar
Sube el repositorio a GitHub, impórtalo en vercel.com y pulsa Deploy. No requiere configuración.
